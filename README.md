# My-eCornell-Portfolio
Includes my Twitter Emotion Detection final project.

Open the file **TwitterSentimentAnalysis.ipynb** to view detailed explanations of the steps I took to conduct performance analysis of a decision tree, random forest, and neural network model to classify Tweets into emotions.
Open the **text.csv** file to see the Kaggle dataset I used to train my models.

A huge thank you to Professor Jule Schatz from UIUC for being my Machine Learning instructor and helping me acquire the skills I needed to create this, as well as for giving my project a shoutout in the Break Through Tech AI Slack channel!

I later used this project as the basis for a beginner-friendly NLP workshop with the Stony Brook Women in Computer Science Club, with over 20 attendees.
The presentation I created can be found [here](https://www3.cs.stonybrook.edu/~wics/pages/blogPosts/2024-2025/nlp.html).
